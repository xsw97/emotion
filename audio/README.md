# 月光背景音乐说明

本项目支持播放德彪西的《月光》（Clair de Lune）作为背景音乐。

## 如何添加月光音频

1. 获取德彪西《月光》的音频文件（MP3 格式）
2. 将音频文件重命名为 `moonlight.mp3`
3. 将文件放入此目录（`/audio/`）

## 使用说明

- 点击侧边栏的"🌙 月光"按钮可以切换月光背景音乐
- 如果音频文件不存在，会自动切换到默认背景音乐（Web Audio API 生成）
- 月光音乐会循环播放
